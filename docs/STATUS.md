# YC Note 進度（2026-10-19）

## 已完成並部署

- Saber fork：`whoishuni/YC-Note`；名稱 YC Note、YC 圖示與各平台識別已替換。
- 租屋系統原生管理頁 https://yckuo.com/rent/admin/notes.php，共用登入、Session、header/footer、選單與 CSRF；舊 `/yc_note/` 導向此頁。
- 只使用租屋管理員帳號；超級管理員預設開放，一般管理員與舊 manager 別名須明確授權。租客、代登入、未授權管理員均無法存取。
- 未開放／唯讀／可編輯三種權限；帳號新增刪除沿用租屋流程。原筆記專用帳號停止登入，歷史資料保留。
- 裝置人工核准、撤銷、個人裝置自助撤銷、超級管理員安全稽核。
- 已核准 App 登入可自動續期至 90 天後；每次請求仍檢查帳號、密碼、角色、裝置與權限。未核准、已過期及已撤銷憑證不會自動復活。
- 整本筆記列表、封面、資料夾名稱、搜尋與分頁、已刪除篩選、歷史原始檔下載。原稿改為含附件的 SBA；管理員只能下載自己的內容。
- 新舊 bearer API 共用資料與授權；舊 App 無需改網址。共享 IP 黑名單、地區限制、輸入偵測、上傳掃描與維護模式。
- YC Note 私有資料庫 11 張表；私有版本程式、憑證與筆記都在 public_html 外。
- 分階段上傳不可變內容，單次 SQL 交易比較整個帳號快照後提交；同一提交代碼重試不新增版本。採用後拒絕舊版逐檔寫入。
- 原稿、附件與同步基準採本機日誌批次發布；實際終止程序後可恢復，失敗可回滾。整本衝突保留副本，不混入另一版本附件。
- PDF 由 App 返回列表同步時預先生成，原稿仍可編輯。網站比對完整原稿／附件雜湊才提供 PDF 預覽與下載；舊 PDF 不標為最新。圖片先解碼，PDF／SVG 背景先完成渲染，逐頁壓縮以減少記憶體。
- 編輯途中改唯讀的「本機保留」、帳號切換防止舊編輯器寫入新帳號、離線限時授權。

## 已驗證

- PHP 服務 85 項、筆記庫／封面／SBA／PDF 完整性 23 項；原子同步 43 項在 SQLite 與隔離 MySQL 通過。API HTTP 38 項。
- 租屋原生 Session／CSRF／控制器／header/footer 70 項；共用安全攔截畫面 53 項。
- Flutter 70 項檢查通過，包括真實 PHP HTTP 同步、回應遺失重試、不同檔案的整本衝突、唯讀、本機程序終止復原、實際 PDF 生成／Ghostscript 渲染；包含匯入 PDF 與 SVG 背景的實際渲染及像素驗證；Dart analyze 通過。
- 額外執行舊 Browse 畫面 golden 比對，6 張現有基準圖仍有約 1–3% 字型／位置差異；已檢視差異，沒有直接更新基準圖。功能導覽測試通過。
- 正式站舊管理頁 302 轉入原生頁；未登入原生頁導回租屋登入。新舊 API 皆 401 JSON，精確新 API 路徑的 PUT／DELETE 能通過 Apache 方法閘門並要求認證。
- 正式站 boot.php 與 .local-root.php 直接請求 403；新 CSS 200；臨時部署入口已移除。
- Xcode 27.1 release 簽署、完整簽章驗證、安裝到實體 iPad 與 CLI 啟動均成功。

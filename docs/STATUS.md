# YC Note 進度（2026-10-20）

## 已完成並部署

- Saber fork：`whoishuni/YC-Note`；名稱 YC Note、YC 圖示與各平台識別已替換。
- 租屋系統原生管理頁 https://yckuo.com/rent/admin/notes.php，共用登入、Session、header/footer、選單與 CSRF；舊 `/yc_note/` 導向此頁。
- 只使用租屋管理員帳號；超級管理員預設開放，一般管理員與舊 manager 別名須明確授權。租客、代登入、未授權管理員均無法存取。
- 未開放／唯讀／可編輯三種權限；帳號新增刪除沿用租屋流程。原筆記專用帳號停止登入，歷史資料保留。
- 裝置人工核准、撤銷、個人裝置自助撤銷、超級管理員安全稽核。
- 已核准 App 登入可自動續期至 90 天後；每次請求仍檢查帳號、密碼、角色、裝置與權限。未核准、已過期及已撤銷憑證不會自動復活。
- 整本筆記列表、封面、資料夾名稱、搜尋與分頁、垃圾桶、整本版本原稿下載及還原。原稿為含附件的 SBA；管理員只能操作與下載自己的內容，唯讀禁止刪除與還原。
- 新舊 bearer API 共用資料與授權；舊 App 無需改網址。共享 IP 黑名單、地區限制、輸入偵測、上傳掃描與維護模式。
- YC Note 私有資料庫 12 張表；私有版本程式、憑證與筆記都在 public_html 外。
- 分階段上傳不可變內容，單次 SQL 交易比較整個帳號快照後提交；同一提交代碼重試不新增版本。採用後拒絕舊版逐檔寫入。
- 原稿、附件與同步基準採本機日誌批次發布；實際終止程序後可恢復，失敗可回滾。整本衝突保留副本，不混入另一版本附件。
- PDF 由 App 返回列表同步時預先生成，原稿仍可編輯。網站比對完整原稿／附件雜湊才提供 PDF 預覽與下載；舊 PDF 不標為最新。圖片先解碼，PDF／SVG 背景先完成渲染，逐頁壓縮以減少記憶體。
- 整本版本記錄原稿及當時的編號附件，網站還原以同一 SQL 交易發布；保留還原前內容、移除較新附件並使衍生 PDF／封面失效。表單以整本指紋防止覆蓋其他裝置的新內容。垃圾桶保留可恢復的原稿；沒有永久清除功能。舊逐檔記錄留在折疊區，只從既有實際內容建立完整初始快照。
- 編輯途中改唯讀的「本機保留」、帳號切換防止舊編輯器寫入新帳號、離線限時授權。

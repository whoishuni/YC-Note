# 官方 Saber 網站閱讀與匯出

整合版本 6 在租屋原生「Saber 雲端」加入本頁解鎖、搜尋、逐頁閱讀、PDF 與原稿下載。官方 App 繼續使用原相容服務；不改 App、密碼、遠端檔案或租屋帳號。

## 身分與解鎖

`admin/notes_cloud.php` 只接受 GET。每次重新驗證租屋 Session、密碼指紋、角色、封鎖、啟用、筆記權限、IP／地區及維護狀態；只讀目前帳號，任何 owner 參數都不能選擇別人。唯讀帳號可以閱讀及匯出。

加密密碼只在瀏覽器以 WebCrypto 衍生不可匯出的 AES 金鑰，驗證官方 `config.sbc` 金鑰封套，再解密路徑及內容。相容上游 AES-SIC／PKCS7、SHA-256 密碼鍵與固定 salt；不擅自改成封套內的隨機鍵。舊 `.sbn` 的雲端內容另有 base64 層。密碼沒有表單 name，不放在 URL、API、日誌、cookie、localStorage、sessionStorage 或 IndexedDB。

鎖定及 pagehide 清除金鑰參照、解密快取、畫布、檔名與下載 URL；15 分鐘無操作自動鎖定。每分鐘驗證 Session，開啟、切頁及匯出前後也重新驗證帳號與權限。X-YC-Owner 與 JSON 身分防止同一瀏覽器切換帳號後沿用舊明文；非同步操作以同頁序號隔離，不能在鎖定後復活。已下載的檔案不會被遠端刪除。

本頁「重新整理」沿用記憶體內金鑰，不必重輸密碼；加密設定改變時需重新解鎖。整頁重新載入不保留金鑰。

## 快照與完整性

伺服器按帳號世代分頁，每頁最多 500 筆密文資料。分頁世代不同回覆 409；正式站等待近期寫入靜止 2 秒，瀏覽器可短暫重試。以原路徑雜湊與不可變版本讀取檔案，伺服器及瀏覽器均比對大小與 SHA-256。零位元組刪除標記不列成筆記；重複解密路徑拒絕混用。

開啟／切頁／匯出檢查目前世代；產生 PDF 或原稿後若又更新，要求重新整理，不下載已知過期結果。缺少附件不產生不完整的匯出。

官方 Saber 仍逐檔同步，不能因此宣稱具備自訂 YC Note 的整本原子提交。靜止時間、世代及雜湊無法證明一次被中斷的 App 批次已完整完成，整體帳號復原流程仍待補齊。

## 內容與 PDF

支援至 SBN 版本 19，包含舊 JSON、BSON、Float32 筆跡、壓力與平滑、螢光筆分色混合、鉛筆材質、圓／矩形、紙張格線、Quill 文字及分離附件。PNG／JPEG／SVG／PDF 背景與圖片、來源頁碼、裁切及 BoxFit 皆保留；SVG 拒絕外部與動態內容。未知版本或不支援的內容明確拒絕，不能用空白頁假裝完成。

PDF 在瀏覽器逐頁渲染再壓縮嵌入 PDF；中文字會保留成像素，文字不可選取，原 PDF 超連結不轉成互動註解。字型依本機後備字型，文字排版可能與 Flutter 有差異。原稿仍以可編輯 SBA（主檔及引用附件）下載；舊 JSON 原稿下載為 SBN。匯出不寫回雲端。

預覽一次只保留一頁畫布；PDF 逐頁嵌入影像並釋放原始像素及畫布，保留壓縮後的 PDF 物件。單檔沿用 50 MB，解密快取最多 200 MB，最大渲染畫素／邊長及 PDF 壓縮資料 120 MB 有界限，超限提示在 Saber 匯出。

PDF.js、BSON、perfect-freehand、pdf-lib、fflate、Neucha，以及 PDF 字碼表、標準字型與解碼器全部本機託管，附授權、固定版本、lockfile 及逐檔 SHA-256 manifest。不使用 CDN，不放寬既有 CSP 的 JavaScript eval；PDF.js 關閉字型 eval 與 WASM，保留本機 JavaScript 解碼後備。

## 驗證

- 143 項服務檢查在 SQLite 與隔離 MySQL 通過；加入靜止時間／世代檢查後 SQLite 146 項通過。
- 159 項租屋原生 HTTP、官方相同 Nextcloud SDK 9 項、共享安全畫面 53 項通過。
- Dart 到 WebCrypto、BSON、座標、附件及原稿 66 項；渲染／PDF／SVG／裁切 32 項。
- 13 份 PDF 以 pypdf 重新開啟，Poppler 渲染比對。包含多語、圖片、鉛筆、形狀及指定 PDF 第二頁背景。
- 隔離網站實際操作錯誤／正確密碼、筆跡、多語、多頁、PDF 背景、產生 PDF 下載連結、同頁更新與鎖定；未以真實密碼做自動測試。
- 正式部署與真實筆記解鎖另依部署回報記錄，不把隔離畫面當成正式驗收。

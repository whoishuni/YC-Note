# YC Note 功能路線

目標是接近 Goodnotes 的非 AI 筆記體驗。這份文件區分現有程式基礎、第一階段新增功能與尚未實作的項目；不是已完成的功能宣告。

## 目前使用方式與範圍

使用者改用官方 App Store Saber，已停止免費側載續簽；自有後台實作原生租屋授權與官方版相容的雲端服務。官方版的本機書寫、名稱、圖示與離線權限不能由網站修改。以下自訂 App 的既有強化保留在 fork，並不會自動出現在官方版；未完成的 Goodnotes 功能也不能只靠伺服器新增。

官方 iPad 已完成租屋登入與實際手寫上傳。網站 v6 已提供瀏覽器解鎖、筆記搜尋、逐頁閱讀、PDF 與可編輯原稿下載，密碼及明文不傳往伺服器；正式使用者筆記解鎖仍待最後確認。接續驗證下載復原、安全搬移舊筆記、完成加密帳號備份還原和配額控制。官方協定逐檔上傳，網站使用世代與附件完整性檢查；不能宣稱它具備原自訂 App 的整本原子版本。

## 已有的 Saber 基礎

從上游程式可確認包含筆、鉛筆、螢光筆、橡皮擦、套索選取、簡易形狀、文字、PDF 與圖片匯入、資料夾、頁面管理、PDF/PNG/原始格式匯出，以及畫布縮放與平移。iPad 上的筆感、手掌防誤觸與大型 PDF 效能仍須實機測量。

## 保留的自訂客戶端既有功能

YC 品牌、租屋系統原生管理模組、共用登入／Session／導覽／帳號流程、管理員明確授權、裝置人工核准／撤銷與長期登入續期、唯讀權限、私人儲存用量、整本版本下載／還原與垃圾桶、以內容雜湊與版本比對同步、衝突完整備份、帳號本機目錄隔離、共享租屋資安引擎與維護模式。僅使用租屋管理員，筆記專用帳號已停止新增與登入。

## 接下來的優先順序

| 階段 | 項目 | 驗收方式 |
| --- | --- | --- |
| 1. 安裝與可靠性 | 官方 App Store 安裝、首次核准、手寫保存、重啟、雙裝置同步、雲端唯讀切換、斷線重試 | 真實 iPad 完成寫入→上傳→使用隔離測試環境下載復原；不刪除使用者原稿，不丟筆跡或附件 |
| 2. 書寫品質 | 筆壓與平滑、手掌防誤觸、Apple Pencil 雙點／擠壓／懸浮、快速換筆、區段擦除、精確套索 | 長時間筆記、斜線、細筆跡與擦除的實測；記錄延遲、發熱與記憶體 |
| 3. 文件與整理 | 筆記本封面、紙張範本、標籤／收藏／書籤、資料夾顏色、頁面複製／排序／旋轉、跨本複製、PDF 目錄與連結 | 百頁以上 PDF；匯入匯出後尺寸、連結、圖片和筆跡完整 |
| 4. 閱讀與學習 | 尺規、遮蔽膠帶、閱讀模式、分頁與多視窗、並排文件、雷射筆、錄音與筆跡時間軸、手動字卡與間隔複習 | 不使用生成式 AI；錄音與筆跡可回放對齊，字卡可匯出 |
| 5. 網站管理 | 官方版已加入瀏覽器解鎖、閱讀、PDF／原稿下載與加密備份；舊自訂筆記保留整本版本還原與垃圾桶；接續配額設定與可驗證完整還原 | 正式筆記預覽、還原演練與跨帳號隔離測試 |
| 6. 同步進階 | 自訂 App 保留原子提交與日誌復原；官方協定採逐檔版本與世代檢查，接續研究可行的衝突與還原流程 | 並行編輯、上傳中斷電、刪除衝突、大型 PDF、磁碟額滿 |

手寫辨識／OCR 屬於辨識模型功能；使用者要求不加入 AI，因此目前不納入預設實作。若之後明確允許本機 OCR，再獨立設計，筆記不傳往第三方辨識服務。

Goodnotes 的 `.goodnotes` 格式不能直接承諾完整相容。優先支援以 PDF 搬移內容，以及 YC Note 自己的可備份原始格式。

## 原自訂客戶端同步的實際限制

- App 的一批原稿／附件修改採伺服器原子提交，本機以日誌批次套用；網站已提供整本歷史下載、還原與垃圾桶。舊逐檔歷史另行保留，不推測不存在的歷史附件配對。
- 正在編輯時可以上傳已保存內容；會修改本機的遠端下載留待返回列表後進行。
- 衝突前複製完整本機筆記目錄，包含 PDF／圖片附件；同本不同檔案各自修改也視為整本衝突，避免混用附件。新 App 將完整副本顯示在「同步衝突備份」並搬移舊完整副本，此更新尚未安裝實機。尚未提供筆畫層級合併。
- 編輯權限被移除時，未儲存內容與附件會以完整副本保留在「本機保留」，可唯讀開啟。完成保留才允許返回；恢復編輯權限後，副本可正常同步。
- 離線權限使用最近一次成功驗證的限時授權。裝置離線時不能立即收到伺服器撤銷，連線後重新驗證，或授權到期後鎖定。
- HTTPS 傳輸；目前不是端到端加密。伺服器擁有者可以管理儲存內容。

功能對照來源：[Goodnotes 筆記工具](https://support.goodnotes.com/hc/en-us/sections/9776129866639-Take-Notes)、[錄音](https://www.goodnotes.com/features/audio-recording)、[學習字卡](https://support.goodnotes.com/hc/en-us/articles/7353756529551-Getting-Started-with-Study-Sets-and-Smart-Learn)。

## 網站下一批功能

1. 裝置最近成功同步、失敗原因、App 版本與必要更新。
2. 每人配額、歷史版本保留期限、可驗證完整備份與還原演練。
3. 標籤、收藏、資料夾管理、批次 PDF／原稿匯出。
4. 可到期的唯讀分享連結、密碼與撤銷控制；明確選取後才分享。

上述為規劃，沒有用未實作的按鈕佔據管理頁。
